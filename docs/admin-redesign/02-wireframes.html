  • 3Три вида центра: Divisions (таблица), Changes (диф v3 → v4 бок о бок, «removed — merged upward»), Mappings (v2 → v4, v3 → v4: source tier → target, AUTO 100%/67%, «1 to resolve»). Mappings — это бывший ConflictResolver, ставший постоянной частью редактора, а не шагом импорта.
  • 4Новая дивизия наследует crest родителя до назначения своего — маркер «borrows crest» из макета.
  • 5Колонку «PLAYERS / 3 RENAMED» макета делим: Players (число + бар) и «vs v3» (бейдж дифа) — две разные величины в одной клетке читались плохо.
  • 6Impact: сколько игроков сменит дивизию и какие турниры читают какие версии — из макета, покрывается DivisionGridMapping + подсчётом по ow_rank.
  • 7Pre-flight чеклист перед Publish; сам Publish (иммутабельно) и Activate (стать гридом воркспейса) — два шага, Activate заблокирован до Publish.
  • 8Sticky-бар = наш стандартный save-bar с итогом черновика. На <1280px правая колонка становится табом «Impact» рядом с Mappings.
